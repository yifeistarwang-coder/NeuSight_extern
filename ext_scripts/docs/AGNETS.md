# Agent 实验执行与记录约定

本文约定 Agent 执行 RTX A6000 实验时应遵循的参考资料和记录方式。具体实验方案与技术细节以以下文档为准，实验过程记录追加在本文末尾。

## 1. 参考文档

| 文档 | 用途 |
|---|---|
| [A6000_EXPERIMENT_PLAN.md](A6000_EXPERIMENT_PLAN.md) | 明确实验目标、配置矩阵、测量口径、执行阶段和交付标准。 |
| [A6000_EXPERIMENT_NOTES.md](A6000_EXPERIMENT_NOTES.md) | 查阅硬件依据、环境要求、命令示例、输出目录、实现待办和历史数据核查。 |

执行前先阅读实验计划，再查阅执行附录。若实际环境或代码行为与文档不一致，先记录差异；涉及实验范围、测量口径或冻结输入的调整，需确认后再执行。

## 2. 执行约定

- 按计划分阶段推进：准备、试跑、正式运行、汇总；满足当前阶段的检查条件后再进入下一阶段。
- 冻结现有预测器权重与 tile 表，A6000 实测数据仅用于评测，不得回填训练数据或用于调参。
- 分开保存试跑、正式实验和补充测试的产物，按物理 GPU 和轮次隔离输出，保留原始数据，不覆盖已完成且有效的结果。
- 如实记录 OOM、依赖问题、trace／parse 错误和输出不完整等情况，不静默缩小 batch、修改精度或将失败项计为零误差。
- 硬件与环境的历史核查仅作为参考；运行前重新检查占用和配置，记录本次实际使用的信息。

## 3. 记录要求

每完成一个阶段、实施关键变更或遇到异常后，在下方追加记录。区分已完成事项、实际观测和待办，不将计划、估算或未经验证的推断写成实验结果。

每条记录应包含：

- **时间与阶段**：执行时间、所属阶段，以及完成、失败或阻塞状态。
- **环境与输入**：本次使用的环境、物理 GPU 及进程内设备映射、代码版本与输入文件哈希；未变化时可引用已有记录。
- **操作与变更**：工作目录、关键命令、参数及修改的文件。
- **产物与验证**：日志和输出路径、完整性检查、有效配置与重复数、实际耗时。
- **结论与后续**：观测结果、异常原因、与方案的差异及下一步；未确认原因标为待核查。
